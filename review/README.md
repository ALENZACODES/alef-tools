# Review Lists

Lists for a person to settle. Nothing in this folder ships.

| File | What it holds |
|---|---|
| `tm-needs-human.json` | Translation-memory entries the checks turned down (packages/translate). `kind: machine` was translated offline and failed a check. `kind: app-pair` is the app's own English failing a rule check: usually a free wording, sometimes a slip worth a look. |
| `tm-report.json` | The counts of the build that wrote the list. |
